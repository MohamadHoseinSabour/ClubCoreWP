# ClubCore - پلتفرم پیشرفته باشگاه مشتریان وردپرس (Customer Club)

افزونه حرفه‌ای و اختصاصی **ClubCore** جهت مدیریت اعضای باشگاه مشتریان، ثبت سریع اعضا توسط مدیران، اتصال یکپارچه با ووکامرس (پشتیبانی کامل از HPOS)، ارسال پیامک‌های اعتبارسنجی و خوش‌آمدگویی بر اساس الگوهای سامانه‌ی ملی‌پیامک (Melipayamak)، و قابلیت ورود و خروج گروهی با ظرفیت بالا طراحی شده است.

---

## ویژگی‌های کلیدی

### ۱. مدیریت هوشمند اعضا و هویت وردپرس
* **تفکیک مفهومی کاربر و عضو:** ساختار دامنه Member از اکانت Identity وردپرس کاملاً مستقل است.
* **ثبت سریع توسط مدیر:** فیلدهای موبایل، نام و نام خانوادگی با امکان ساخت خودکار حساب کاربری بدون نمایش یا افشای پسورد.
* **جلوگیری چندلایه‌ای از رکوردهای تکراری:** بررسی در جدول اختصاصی باشگاه، متای کاربران وردپرس و اطلاعات صورت‌حساب ووکامرس.
* **نرمال‌سازی ارقام و شماره موبایل:** تبدیل خودکار ارقام فارسی و عربی به ارقام استاندارد، حذف فاصله‌ها و کاراکترهای زائد، تبدیل پیشوندهای `+98`, `0098`, `98` به فرمت کانونیکال `09XXXXXXXXX`.

### ۲. زیرساخت اختصاصی پیامک و ملی‌پیامک (Melipayamak)
* **پشتیبانی از هر دو سیستم احراز هویت:** وب‌سرویس کلاسیک (BaseServiceNumber با نام‌کاربری/رمز) و کنسول جدید ملی‌پیامک (Token-based).
* **پشتیبانی هوشمند از الگوها (Pattern):** تفکیک متغیرها، ارسال صرفاً مقادیر متغیرها بدون ارسال کل متن قالب، پشتیبانی از پارامترهای `{first_name}`, `{last_name}`, `{full_name}`, `{phone}`.
* **ارسال پیامک آزمایشی (Test SMS):** تست صحت اتصال به API و دریافت وضعیت اعتبار بدون نیاز به ساخت مشتری آزمایشی.
* **تاریخچه کامل پیامک‌ها:** ثبت شناسه رهگیری (recId)، خطاهای سرویس‌دهنده با پیام‌های ترجمه‌شده فارسی، و قابلیت ارسال مجدد (Resend) با نرخ محدودساز (Rate Limiting).
* **درایور تست (FakeSmsProvider):** قابلیت شبیه‌سازی کامل رفتار بدون ارسال واقعی و بدون مصرف اعتبار.

### ۳. درون‌ریزی و برون‌بری قدرتمند (Import & Export)
* **پشتیبانی از منابع سه‌گانه:** فایل‌های CSV، فایل‌های اکسل (XLSX) و متن کپی‌شده از کلیپ‌بورد (Clipboard Copy/Paste).
* **مقاومت در برابر فایل‌های سنگین:** پردازش تکه‌تکه (Chunked/Batch Processing) به صورت ۵۰۰ ردیف در هر بسته جهت جلوگیری از خطای کمبود حافظه در فایل‌های بزرگ.
* **تشخیص هوشمند جداکننده‌ها و پشتیبانی کامل UTF-8 و BOM:** جهت جلوگیری از بهم‌ریختگی حروف فارسی در اکسل.
* **پیش‌نمایش (Preview) و اجرای آزمایشی (Dry Run):** بررسی اعتبارسنجی‌ها، خطاها و سطرهای تکراری قبل از ثبت قطعی.
* **امنیت در برابر تزریق فرمول (CSV Formula Injection):** خنثی‌سازی خودکار کاراکترهای خطرناک مانند `=`, `+`, `-`, `@`.

### ۴. هماهنگی کامل با ووکامرس و HPOS
* **پشتیبانی اختصاصی از High-Performance Order Storage (HPOS):** بدون نوشتن حتی یک کوئری مستقیم روی جدول سنتی `wp_posts`.
* **ثبت‌نام خودکار (Auto Enrollment):** قابلیت فعال‌سازی عضویت خودکار مشتریان هنگام ثبت‌نام یا بعد از اولین سفارش موفق.
* **آمار و سفارش‌های مشتری:** نمایش مجموع خرید، تعداد سفارش‌ها و تاریخ آخرین سفارش با کش و بدون کوئری‌های تکراری N+1.

### ۵. امنیت، حریم خصوصی و دسترسی‌ها
* **امنیت چندلایه‌ای:** استفاده اجباری از Nonce، اعتبارسنجی دسترسی‌ها (Capabilities)، بررسی توابع Sanitization و Escaping و کوئری‌های امن با `$wpdb->prepare`.
* **سیستم لاگ و ممیزی (Audit Log):** ثبت تمامی وقایع با ماسک کردن شماره تلفن و هش کردن آدرس‌های IP.
* **سیاست نگهداری داده‌ها (Data Retention):** امکان تنظیم زمان حذف خودکار لاگ‌های قدیمی و سازگاری با فرآیند Privacy وردپرس.
* **رابط کاربری راست‌چین (RTL) و شخصی‌سازی ظاهر:** تعریف متغیرهای CSS و بررسی هوشمند کنتراست رنگ‌ها طبق استانداردهای WCAG.

## ساختار دایرکتوری و معماری
معماری پروژه بر اساس مدل لایه‌ای استاندارد (Clean / Layered Architecture) پیاده‌سازی شده است:
```text
clubcore/
├── clubcore.php                 # فایل اصلی و هدر افزونه
├── uninstall.php                # اسکریپت حذف ایمن
├── composer.json                # نیازمندی‌ها و نگاشت‌های PSR-4
├── phpunit.xml                  # پیکربندی تست‌ها
├── phpstan.neon                 # تحلیل ایستای کد
├── phpcs.xml                    # استانداردهای کدنویسی وردپرس
├── src/
│   ├── Domain/                  # لایه منطق هسته کسب‌وکار
│   │   ├── Entity/              # Member, SmsLog, AuditEntry, ImportJob
│   │   ├── ValueObject/         # PhoneNumber, MembershipSource
│   │   ├── Contract/            # اینترفیس‌های ریپازیتوری، پیامک، لاگر
│   │   └── Exception/           # استثناهای دامنه
│   ├── Application/             # لایه کاربرد و UseCaseها
│   │   ├── Service/             # MemberService, SmsService, ImportService, WooCommerceService
│   │   ├── UseCase/             # CreateMemberUseCase
│   │   └── Dto/                 # CreateMemberRequest, ImportRowDto
│   ├── Infrastructure/          # لایه زیرساخت و ارتباط با WP / دیتابیس / API
│   │   ├── WordPress/           # MemberRepository, SmsLogRepository, AuditLogRepository, Settings, Migrations
│   │   ├── Sms/                 # MelipayamakProvider, FakeSmsProvider, SmsErrorMapper
│   │   ├── Pattern/             # PatternParser, VariableRegistry
│   │   ├── Import/              # CsvParser, XlsxParser, ClipboardParser, ImportProcessor
│   │   ├── Export/              # CsvExporter, XlsxExporter
│   │   └── WooCommerce/         # WooCommerceDetector, CustomerMatcher, WooCommerceIntegration
│   └── Presentation/            # لایه نمایش و پنل مدیریت
│       ├── Admin/               # AdminBootstrap, MenuManager, AssetManager
│       └── Table/               # MembersListTable, SmsLogsListTable, AuditLogsListTable
├── assets/                      # کدهای CSS و JS راست‌چین پنل ادمین
├── templates/                   # قالب‌های صفحات ادمین و تب‌های تنظیمات
├── tests/                       # آزمون‌های واحد و Integration
└── docs/                        # اسناد معماری، دیتابیس، امنیت و API
```
